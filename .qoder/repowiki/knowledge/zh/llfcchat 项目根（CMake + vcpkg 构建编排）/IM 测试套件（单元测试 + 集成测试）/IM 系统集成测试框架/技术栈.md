Win32 API（Job Object、CreateProcessA、GetTempPathA）用于进程管理；Boost.Asio（tcp::socket/io_context/resolver）用于端口探测与 TCP 通信；Boost.Beast 用于 HTTP 请求；nlohmann/json 用于 JSON 编解码；mysql-concpp JDBC 驱动与 hiredis C 库分别连接 MySQL（127.0.0.1:3308/llfc）和 Redis（127.0.0.1:6380）。编译期通过 IM_REPO_ROOT / IM_BUILD_CONFIG 宏定位 out/run/<Config>/ 下的可执行文件。
