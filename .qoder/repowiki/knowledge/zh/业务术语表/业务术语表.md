### GateServer
- 定义：网关服务，负责处理客户端的 HTTP 短连接请求，包括用户注册、登录、重置密码等。作为外部请求的统一入口，GateServer 会调用 StatusServer 获取可用的 ChatServer 节点地址，然后返回给客户端建立 TCP 长连接。
- 别名：网关服务、gateway

### ChatServer
- 定义：聊天服务，基于 TCP 长连接处理实时消息转发、好友申请认证、文件传输等核心聊天功能。每个 ChatServer 实例维护用户的在线状态和会话信息，支持多用户并发连接。
- 别名：聊天服务器、chat service

### StatusServer
- 定义：状态管理服务，负责维护 ChatServer 节点的存活状态和负载信息，为 GateServer 提供负载均衡服务发现。同时管理用户的 Token 验证和用户登录位置信息。
- 别名：状态服务、status service

### VarifyServer
- 定义：验证服务，独立的 Node.js 服务，专门处理邮箱验证码的生成、发送和验证。通过 gRPC 接口被其他服务调用，支持注册、重置密码等需要邮箱验证的场景。
- 别名：验证服务、verify service、邮箱服务

### ResourceServer
- 定义：资源服务，负责文件上传下载、头像存储、聊天图片等资源的管理。支持断点续传、分片上传、进度显示等功能，为聊天系统中的多媒体内容提供存储服务。
- 别名：资源服务、file service

### Token
- 定义：一次性访问令牌，由 StatusServer 生成 UUID 格式的字符串，存储在 Redis 中（key: utoken_{uid}）。用于用户登录后建立 TCP 连接的鉴权，ChatServer 通过比对 Redis 中的 Token 来验证用户身份。
- 别名：访问令牌、auth token

### 分布式锁
- 定义：基于 Redis 实现的分布式锁机制，使用 SET lockKey identifier NX EX lockTimeout 命令。主要用于防止同一用户并发登录造成状态混乱，支持超时自动释放和死锁检测。锁前缀为 'lock_'，持有时间默认10秒，重试超时5秒。
- 别名：分布式锁、distributed lock、Redis锁

### 粘包/拆包
- 定义：TCP 字节流协议的消息边界问题。项目通过自定义消息头（长度+类型）解决粘包和拆包问题，接收端根据消息头中的长度字段判断完整消息边界，处理半包读取和多包合并的情况。
- 别名：粘包处理、消息边界、TCP粘包

### 心跳机制
- 定义：客户端定时发送心跳包（ID_HEART_BEAT_REQ）保持 TCP 连接活跃，服务端超时未收到心跳则判定用户离线并清理相关资源。用于维持长连接的生命周期管理和用户在线状态更新。
- 别名：心跳保活、keepalive

### 踢人逻辑
- 定义：用户异地登录时的处理机制。单服情况下直接关闭旧连接；跨服情况下通过 gRPC 通知目标 ChatServer 踢出旧连接。确保同一用户在同一时间只能在一个设备上保持有效连接。
- 别名：踢人、kick user、异地登录处理

### 聊天线程
- 定义：聊天会话的概念，分为私聊（private）和群聊（group）两种类型。每个聊天线程对应一个 thread_id，存储在该线程中的所有聊天记录。私聊线程关联两个用户，群聊线程关联多个成员。
- 别名：聊天会话、chat thread、会话

### 好友申请
- 定义：用户添加好友的申请流程，包含申请状态（待确认、已同意、已拒绝）和申请描述。通过 friend_apply 表存储申请记录，支持双向好友关系的建立和管理。
- 别名：好友申请、friend request、apply

### 断点续传
- 定义：大文件传输的可靠性机制，支持文件分片上传和断点续传。客户端记录已上传的分片信息，服务器端检查重复分片避免重复传输，支持传输进度显示和中断恢复。
- 别名：断点续传、resumable upload

### WebRTC信令
- 定义：音视频通话的信令交换机制，通过自研的信令服务器实现 P2P 连接的建立。使用 coturn 服务器进行 NAT 穿透，支持视频通话、语音通话等实时通信功能。
- 别名：信令服务器、signaling、WebRTC信令
