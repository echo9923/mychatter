根级 CMakeLists.txt 通过 add_subdirectory(server) 和 add_subdirectory(client/llfcchat) 将服务端与客户端纳入同一构建树，强制使用 Ninja Multi-Config 生成器并禁止源码目录内构建；vcpkg.json 集中声明 boost-asio/beast、grpc、protobuf、hiredis、mysql-connector-cpp、qt5-base/imageformats 等跨子模块共享依赖，所有子模块通过统一的 cmake/Dependencies.cmake 与 cmake/GrpcCodegen.cmake 获取依赖与 gRPC 代码生成能力。server 子模块提供 ChatServer/GateServer/ResourceServer/StatusServer 四个微服务并通过 Protocol Buffers 定义 RPC 接口，client 子模块以 Qt5 为 UI 层通过 TCP/gRPC 与后端通信，webrtc_demo 作为独立 Node.js 信令服务器配合 WebRTC P2P 音视频直连，sql_backups 提供 MySQL DDL 与数据快照供服务端持久化使用。
