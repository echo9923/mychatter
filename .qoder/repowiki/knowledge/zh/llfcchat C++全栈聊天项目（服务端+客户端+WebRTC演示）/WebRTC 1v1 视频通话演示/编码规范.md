- 信令消息统一通过 JSON 字符串传输，并以 `type` 字段区分 join/joined/ready/offer/answer/ice/leave/peer-left/error/full 等状态。
- WebSocket 发送封装为 `send(ws, data)` 函数，先检查 `ws.readyState === ws.OPEN` 再序列化发送，避免向已关闭连接写入。
- 房间生命周期围绕 `rooms` Map 管理：join 时根据 roomId 取或建 Set 并 add，leave/close 时 removeFromRoom 清理并广播 peer-left 事件。
- 前端所有 UI 状态通过 `setStatus()` 和 `setRole()` 两个辅助函数更新，保持 DOM 与逻辑解耦。
