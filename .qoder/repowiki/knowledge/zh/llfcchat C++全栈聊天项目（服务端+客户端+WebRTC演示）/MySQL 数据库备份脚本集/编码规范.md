- 所有表定义均以 DROP TABLE IF EXISTS + CREATE TABLE 开头，并配合 SET FOREIGN_KEY_CHECKS = 0/1 包裹以保证导入安全。
- 表注释采用 `-- ----------------------------\n-- Table structure for xxx\n-- ----------------------------` 的分隔注释风格。
- 主键统一使用 `USING BTREE`，索引命名遵循 `idx_字段组合` 或 `uniq_字段组合` 前缀约定。
- 时间戳字段统一使用 `timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP`，更新时自动刷新使用 `ON UPDATE CURRENT_TIMESTAMP`。
- 多字节文本字段统一使用 `CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci` 以支持中文及 emoji。
