该模块为纯 SQL 文本文件集合，由 Navicat Premium Data Transfer 导出，按时间顺序保存了 llfc 数据库的多版本快照：
- `llfc2.sql`（2025-06-22）：最完整的早期结构，包含 user、friend、friend_apply、private_chat、group_chat、group_chat_member、chat_thread、chat_message 等表。
- `llfc3.sql`（2025-07-24）：精简版，仅保留核心表结构与少量测试数据。
- `chat_message.sql`（2025-07-24）：单独提取的 chat_message 表结构。
- `llfc.sql`（2026-02-07）：最新完整备份，在 chat_message 中新增 msg_type 字段以支持图片/视频/文件消息类型。
各文件相互独立，均可直接通过 `mysql -u ... -p llfc < file.sql` 导入，无依赖关系。
