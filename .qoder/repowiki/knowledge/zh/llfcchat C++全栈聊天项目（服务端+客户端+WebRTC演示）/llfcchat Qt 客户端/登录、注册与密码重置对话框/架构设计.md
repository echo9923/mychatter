模块由三个独立的 QDialog 子类（LoginDialog、RegisterDialog、ResetDialog）组成，每个对话框对应一个 .ui 界面文件，通过 `Ui::` 命名空间的前向声明解耦 UI 与逻辑。
- 网络层：通过单例 HttpMgr/TcpMgr/FileTcpMgr 发起 HTTP 登录/注册/重置请求，并建立聊天服务器与资源服务器的 TCP 长连接；对话框仅通过信号（如 `sig_connect_tcp`、`sig_connect_res_server`）与这些管理器交互，不直接持有网络对象。
- 回调机制：每个对话框维护 `QMap<ReqId, std::function<void(const QJsonObject&)>> _handlers`，在 `initHttpHandlers()` / `initHandlers()` 中按 ReqId 注册 lambda 处理响应 JSON，统一由 `slot_xxx_mod_finish` 分发。
- 状态提示：使用 `QMap<TipErr, QString> _tip_errs` 集中管理错误提示，配合 `showTip` + `repolish` 动态刷新样式。
- 页面跳转：通过信号（`switchRegister`、`switchReset`、`sigSwitchLogin`、`switchLogin`）通知上层切换对话框，实现登录→注册→重置的导航流。
